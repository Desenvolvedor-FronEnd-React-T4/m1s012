2. Extensões do VS Code

Instale pela aba de Extensões (Ctrl+Shift+X), buscando pelo nome ou colando o identificador. O depurador de JavaScript já vem embutido no VS Code — não precisa instalar nada para depurar Node.

ExtensãoIdentificadorO que fazPor que ajuda nesta semana
Live Serverritwickdey.LiveServerServidor local com recarregamento automáticoNecessário para depurar o front-end (Ex4 ⭐) e para testar <script type="module">
Error Lensusernamehw.errorlensMostra os erros na própria linhaAjuda a achar o require no meio de um projeto ESM
npm Intellisensechristian-kohler.npm-intellisenseAutocompleta nomes de pacotes no import/requireMenos erro de digitação em prompt-sync e chalk
Path Intellisensechristian-kohler.path-intellisenseAutocompleta caminhos de arquivosAjuda a acertar o ./perguntas.js com a extensão
ESLintdbaeumer.vscode-eslintAponta problemas no JavaScript enquanto você digitaPega variáveis não definidas e mistura de sistemas antes de rodar (exige configuração do projeto)
Prettier - Code formatteresbenp.prettier-vscodeFormata o código ao salvarMantém os módulos legíveis
DicaVocê não precisa instalar todas. Se for escolher só uma para começar, escolha o Live Server; depois, o Error Lens. Se algum identificador não aparecer na busca, procure pelo nome da extensão.

3. Ferramentas e sites úteis (gratuitos)

  • Node.js (versão LTS) — nodejs.org: instalador oficial e documentação.
  • npm (registro de pacotes) — npmjs.com: pesquise um pacote, veja downloads semanais, versões e o mantenedor antes de instalar.
  • Calculadora de semver — semver.npmjs.com: veja que versões o ^4.1.2 e o ~4.1.2 aceitam.
  • nvm-windows — github.com/coreybutler/nvm-windows: alternar entre versões do Node (útil para ver o ERR_REQUIRE_ESM em Node antigo × o TypeError em Node novo).
  • pnpm e Yarn — pnpm.io e yarnpkg.com: gerenciadores alternativos (apenas para conhecer).
  • chalk — github.com/chalk/chalk e prompt-sync — npmjs.com/package/prompt-sync: os dois pacotes do Quiz da Copa.
